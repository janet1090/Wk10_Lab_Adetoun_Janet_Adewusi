# Employment Application — JavaFX and MySQL

A desktop employment application form developed as a Java coursework project. The application collects applicant information, validates required fields, and saves submissions to a MySQL database.

## Features

- JavaFX form with text fields and selection controls
- Required-field validation
- Storage of application records in MySQL
- JDBC database connection and a prepared statement for inserting records

## Technologies

- Java and JavaFX
- MySQL
- JDBC
- Eclipse IDE

## Project files

The `Wk10_Lab_Adetoun_Janet_Adewusi` folder contains the Java source code and `W10_EmploymentApplication.sql` database script.

## Running the project

1. Open the project in Eclipse and configure JavaFX and the MySQL JDBC connector.
2. Run the SQL script in MySQL to create the required database objects.
3. Configure your local database connection in `Database.java`. Keep real passwords out of public repositories.
4. Run `Main.java`.
